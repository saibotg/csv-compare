# CSV-Compare

Powershell-Script to compare two csv files.

## Execution

### Windows

```
.\csv_vergleich.ps1 -Datei1 .\datei01.csv -Datei2 .\datei02.csv -IdSpalte "ID" -Mapping .\mapping.csv
```

### Linux

```
./csv_vergleich.ps1 -Datei1 ./datei01.csv -Datei2 ./datei02.csv -IdSpalte "ID" -Mapping ./mapping.csv
```
